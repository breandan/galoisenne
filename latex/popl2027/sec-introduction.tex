\section{Introduction}\label{sec:intro}

A missing delimiter or mistyped keyword can turn an otherwise meaningful program into a string outside the programming language. The parser can establish that the text is invalid, but not what the programmer intended. Suppose the editor responds by opening a menu of candidate repairs. What should that menu contain? We propose each suggestion should be syntactically valid, probable in context, and close to the original text under a small edit distance. Producing one string with any one of these properties is easy. Producing a short menu that satisfies all three---without overlooking the intended repair---is considerably harder.

This paper studies that problem for syntax defined by an arbitrary context-free grammar. Let \(G\) describe the language, let \(\err\sigma\notin\mathcal{L}(G)\) be an invalid token sequence, and let \(L(\err\sigma,d)\) denote the strings within \(d\) Levenshtein edits of \(\err\sigma\). The natural candidate space is
\[
  \ell_\cap = \mathcal{L}(G)\cap\mathcal{L}\big(L(\err\sigma,d)\big).
\]
The grammar enforces validity, the edit language enforces locality, and a probabilistic model supplies naturalness. Since the edit language is finite, \(\ell_\cap\) is finite; by construction, it contains every valid repair within the chosen radius. The problem is therefore not how to guess a repair directly, but how to represent this finite language compactly and recover its most probable members quickly.

Prior approaches tend to commit before this candidate space has been adequately explored. Classical error-correcting parsers return one repair, or the set minimizing a hand-designed cost~\cite{aho1972minimum,diekmann2018dont}. They provide strong syntactic guarantees, but minimum cost need not determine intent when several repairs are tied or nearly tied. Learning-based systems model repairs statistically~\cite{yasunaga2021break,sakkas2022seq2parse}, but search a vastly larger space of strings and rely on approximate decoding, grammar-specific recovery, or filtering after generation. In either case, ranking is powerless if the intended repair never enters the candidate set. For local syntax errors, candidate coverage must be a first-class objective: before choosing well, a repair system must retrieve broadly.

Our approach makes the local search space explicit. We construct an acyclic, \(\varepsilon\)-free Levenshtein automaton denoting every string within distance \(d\) of \(\err\sigma\), then intersect it with the grammar. Directly materializing the classical Bar--Hillel product grammar introduces many unreachable and nongenerating productions. Instead, we exploit a correspondence between Bar--Hillel intersection and CFL reachability. A matrix fixed point identifies which automaton paths derive which nonterminals; a second pass records their provenance as a generalized regular expression denoting all and only the strings in \(\ell_\cap\).

This representation turns repair into constrained decoding rather than unconstrained generation. Brzozowski derivatives reveal the terminals that can legally extend a partial repair, allowing a probabilistic decoder to traverse \(\ell_\cap\) incrementally without rejection sampling. A lightweight \(c\)-gram model retrieves many candidates, and a learned reranker orders them for presentation. Syntax is enforced by construction, edit locality is exact, and statistical modeling is reserved for the genuinely ambiguous task of choosing among valid nearby programs.

This paper makes three contributions. First, it formulates bounded syntax repair as exact language intersection and gives a practical construction for arbitrary context-free grammars. Second, it shows that intersection nonemptiness for a CFG and an acyclic NFA is decidable in \(\mathcal{O}\big(\log^2|Q|+\log(|Q||V|)\big)\) parallel time using \(\mathcal{O}(|Q|^2|V|)\) processors, and develops derivative-based decoding algorithms. Third, it implements these ideas in Tidyparse on multicore CPUs and GPUs. On naturally occurring Python errors of up to three lexical edits and eighty tokens, Tidyparse operates within a ten-second budget and achieves up to a fivefold improvement in top-1 repair precision over prior systems under comparable resource limits.

The next section reviews the formal ingredients behind this construction: context-free grammars, finite automata, generalized regular expressions, Brzozowski derivatives, and Bar--Hillel intersection.
