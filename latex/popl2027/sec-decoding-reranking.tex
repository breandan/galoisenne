\clearpage\section{Decoding and reranking}\label{sec:decoding_reranking}

The construction above gives us an exact finite language, \(\ell_\cap=\mathcal{L}(G)\cap\mathcal{L}\big(L(\err\sigma,d)\big)\), whose contents are precisely the valid words within $d$ edits of $\err\sigma$. What remains is a ranking problem: among the words that are valid and nearby, which should be shown first? In selecting these repairs, our primary considerations will be (1) latency and (2) fidelity -- within a few hundred milliseconds, we must produce a set that anticipates with high probability the author's intended repair. We separate this task into two subproblems: \textit{support} and \textit{ranking}. The support criterion must ensure no member of $\ell_\cap$ is lost and ranking ensures probability mass is maximized by the top-$k$ results.

\subsection{Derivative-guided exact decoding}

Let $e_\cap$ be the star-free generalized regular expression produced by
Theorem~\ref{thm:witness_construction}, so
$\mathcal{L}(e_\cap)=\ell_\cap$.  Brzozowski derivatives expose the legal
continuations of a prefix without enumerating the rest of the language.  For a
residual expression $e$, define
\[
  \mathsf{Next}(e) = \{a\in\Sigma \mid \mathcal{L}(\partial_a e)\neq\varnothing\}, \qquad \mathsf{Done}(e) \iff \varepsilon\in\mathcal{L}(e).
\]
A left-to-right decoder keeps a priority queue of triples
$\langle\sigma,e,s\rangle$, where $e=\partial_\sigma e_\cap$ and $s$ is a running cost.  Popping a prefix and pushing
\[
  \big\langle \sigma a,\partial_a e, s - \log P(a\mid \sigma)\big\rangle \qquad(a\in\mathsf{Next}(e))
\]
performs best-first search over the prefix tree of $\ell_\cap$.  If
$\mathsf{Done}(e)$, the current prefix is emitted as a complete repair, with an
optional end-of-string cost $-\log P(\mathtt{EOS}\mid\sigma)$.

\begin{lemma}[Derivative decoder support]\label{lem:derivative_decoder_support}
  Assume $\ell_\cap$ is finite and the decoder never prunes a queue element.
  Then every emitted string lies in $\ell_\cap$, and every string in
  $\ell_\cap$ is eventually emitted.
\end{lemma}

\begin{proof}
  The invariant $e=\partial_\sigma e_\cap$ holds initially and is preserved by
  each transition.  If the decoder emits $\sigma$, then $\varepsilon\in\mathcal{L}(\partial_\sigma e_\cap)$, hence
  $\sigma\in\mathcal{L}(e_\cap)=\ell_\cap$.  Conversely, if $\tau=a_1\cdots a_n\in\ell_\cap$, then every strict prefix
  $a_1\cdots a_i$ has nonempty residual language, so $a_{i+1}\in\mathsf{Next}(\partial_{a_1\cdots a_i}e_\cap)$
  until the final nullable residual is reached. The prefix tree of a finite
  language is finite, so all of these queue elements are eventually popped.
  Since the state of a queue element is indexed by the emitted prefix rather than by a
  parse derivation, each word has a single path through the prefix tree.
\end{proof}

Thus derivative decoding gives an exact admissibility layer.  If end-of-string
is treated as an ordinary transition and scores are negative log probabilities,
all edge costs are nonnegative; the same queue is Dijkstra search on the prefix
DAG and emits complete repairs in nondecreasing model cost.  With a timeout, it
becomes an anytime top-$k$ approximation whose recall is determined only by the
visited prefix set.  The remaining design choice is therefore the scoring oracle
$P(a\mid\sigma)$, which determines the order in which the finite support is
explored.


\subsection{Fast Markov retrieval}

The simplest low-latency scorer is a smoothed $n$-gram model.  For order $c$, let $h_c(\sigma)$ be the last $c-1$ symbols of $\sigma$, padded on the left, and let $C(h,a)$ be the count of token $a$ after history $h$ in valid programs.  For our experiments, we use the Laplace-smoothed conditional,
\[
  P_c(a\mid\sigma) = \frac{C\big(h_c(\sigma),a\big)+\lambda} {\sum_{b\in\Sigma\cup\{\mathtt{BOS}, \mathtt{EOS}\}} C\big(h_c(\sigma),b\big) +\lambda(|\Sigma|+1)}.
\]
The derivative decoder can query this table with no neural inference and no parser call.  Its state update is simply \( (\sigma,e,s) \longmapsto (\sigma a,\partial_a e,s-\log P_c(a\mid\sigma)), \) so it can often saturate small intersections and sample large intersections without replacement under an interactive latency budget.

The weakness is fidelity.  The Markov state is the explicit suffix $h_c(\sigma)$, so \( h_c(\sigma)=h_c(\tau) \quad\Longrightarrow\quad P_c(\cdot\mid\sigma)=P_c(\cdot\mid\tau). \) This identifies contexts that a repair model should keep separate: delimiter balance, indentation regime, nearby binding structure, and the side of an ambiguous syntactic pattern already selected by the prefix. Thus $n$-grams are a good latency baseline and expose a large candidate set quickly but do not, by themselves, solve ranking.

\subsection{Constrained LLM decoding}

A direct way to obtain high-fidelity scores is to query a conditional language model at every prefix.  Given the broken snippet and a residual $e$, the masked conditional is
\[
  P_\theta^e(a\mid\err\sigma,\sigma) = \begin{cases}
    \displaystyle
    \frac{P_\theta(a\mid\err\sigma,\sigma)} {\sum_{b\in\mathsf{Next}(e)} P_\theta(b\mid\err\sigma,\sigma)} & a\in\mathsf{Next}(e),\\[1.0em]
    0 & \text{otherwise.}
  \end{cases}
\]
A beam decoder of width $B$ then maintains
\[
  \mathcal{B}_{i+1} = \operatorname{Top}_B \left\{
    \left\langle\sigma a,\partial_a e,
    s-\log P_\theta^e(a\mid\err\sigma,\sigma)\right\rangle
    \middle|
    \langle\sigma,e,s\rangle\in\mathcal{B}_i,
  a\in\mathsf{Next}(e)
  \right\}.
\]
This has the right conditional information: the score may depend on the broken
program, the candidate prefix, and long-range semantic cues.  It has two
problems as a first-stage retriever.

First, constrained LLM decoding is expensive in exactly the loop where we
need high throughput.  Even with batching, each beam step requires transformer
logits for many active prefixes; the grammar mask removes illegal successors
after the forward pass, but it does not make the forward pass cheap.  The cost
scales roughly with the explored frontier,
\[
  T_{\mathrm{LLM}} \approx \sum_i |\mathcal{B}_i|\,T_\theta(|\err\sigma|+i),
\]
whereas a finite-state scorer updates in constant time per edge.

Second, any fixed beam sacrifices support completeness.  Let $\operatorname{Pref}_i(\ell_\cap)$ be the set of length-$i$ prefixes of repairs. A beam search is complete for all possible scoring functions only if
\[
  B \geq \max_i |\operatorname{Pref}_i(\ell_\cap)|,
\]
which is exhaustive enumeration in disguise.  When $B$ is smaller, a prefix can be pruned before its probability is disambiguated by later tokens; every repair below that prefix then becomes unreachable. We call this the \textit{decoder--retriever gap}: a high-fidelity model can still recover less mass from $\ell_\cap$ than a weaker model that can afford to enumerate much more of the support.

This bottleneck, as we will show, is problematic: under realtime constraints, beam search over the constrained langauge yields in highly suboptimal top-$k$ results. Instead, we will try to recover some of the throughput properties of the Markov model, with higher-fidelity state tracking.

\subsection{Weighted Nederhof retrieval}

A better finite-state scorer replaces the explicit suffix state with a learned weighted deterministic finite automaton (WDFA).  We obtain its support from Nederhof's regular approximation of the grammar~\cite{nederhof2000practical}; we write the unfolding depth as $h$.

Let
\[
  \mathcal{R} = \{R_A=(Q_A,\delta_A,\iota_A,F_A) \mid A\in V\}, \qquad \delta_A\subseteq Q_A\times(\Sigma\cup V\cup\{\varepsilon\})\times Q_A,
\]
be the recursive transition network (RTN) for the CFG
$G=\langle V,\Sigma,P,S\rangle$.  An arc $p\overset{B}{\longrightarrow}q$ is a call to $R_B$.  Nederhof's $h$-RTN approximation constructs a finite automaton $\alpha_h$ as follows. For the first $h$ call levels, replace each call edge by a fresh copy of the callee:
\[
  p\overset{B}{\longrightarrow}q \quad\leadsto\quad p\overset{\varepsilon}{\longrightarrow}\iota_B' \quad\text{and}\quad f_B'\overset{\varepsilon}{\longrightarrow}q \quad(f_B'\in F_B').
\]
At depth $h$, remaining call edges are connected to shared copies of the
corresponding nonterminal automata rather than unfolded again.  After
$\varepsilon$-removal, determinization, and minimization, the result is a DFA
whose language overapproximates the CFG\@.

\begin{lemma}[Nederhof support cover]\label{lem:nederhof_support_cover}
  For every unfolding depth $h\geq0$, \( \mathcal{L}(G) \subseteq \mathcal{L}(\alpha_h)\). Consequently, for every broken string $\err\sigma$ and edit radius $d$,
  \[
    \ell_\cap =\mathcal{L}(G)\cap\mathcal{L}\big(L(\err\sigma,d)\big) \subseteq \widehat\ell_{h,\cap} =\mathcal{L}(\alpha_h)\cap\mathcal{L}\big(L(\err\sigma,d)\big).
  \]
\end{lemma}

\begin{proof}
  Every derivation in $G$ has an equivalent well-nested accepting run in the
  RTN for $S$.  We map such a run to a path in $\alpha_h$.  Terminal and
  $\varepsilon$ arcs are copied directly.  A nonterminal call at depth
  $<h$ is simulated by entering the fresh callee copy and returning from one of
  its final states to the original continuation state.  A call at depth
  $\geq h$ is simulated in the same way through the shared callee copy.  The
  finite automaton may forget which call site caused a later return, which is
  why it can accept extra strings, but every stack-disciplined RTN run remains
  an ordinary path.  Subsequent $\varepsilon$-removal, determinization, and
  minimization preserve the accepted language.  Thus
  $\mathcal{L}(G)\subseteq\mathcal{L}(\alpha_h)$.  Intersecting both sides
  with the same Levenshtein language preserves inclusion.
\end{proof}

We then attach weights without changing the support.  Let
$\alpha_{h,\hat\theta}$ be the weighted version of $\alpha_h$, with deterministic
transition function $\delta$, initial state $q_0$, transition probabilities
$w(q,a)>0$ on all retained arcs, and final probabilities $w_F(q)>0$ at accepting
states.  With proper normalization, it defines
\[
  P_{\hat\theta}(a_1\cdots a_n) = \left(\prod_{i=1}^n w(q_{i-1},a_i)\right) w_F(q_n), \qquad q_i=\delta(q_{i-1},a_i).
\]
The positive-weight condition gives the weighted support cover
\[
  \ell_\cap \subseteq \widehat\ell_{h,\cap} \subseteq \operatorname{supp}(P_{\hat\theta}).
\]
Hence every true repair receives nonzero probability under the WDFA proposal.
Conditioning on the finite repair overapproximation yields
\[
  P_{\hat\theta}^{h,\cap}(\sigma) = \frac{P_{\hat\theta}(\sigma)} {\sum_{\tau\in\widehat\ell_{h,\cap}}P_{\hat\theta}(\tau)} \qquad(\sigma\in\widehat\ell_{h,\cap}),
\]
and, when an exact grammar filter is applied before presentation, the same
weights rank the exact set by
\[
  P_{\hat\theta}^{\cap}(\sigma) = \frac{P_{\hat\theta}(\sigma)} {\sum_{\tau\in\ell_\cap}P_{\hat\theta}(\tau)} \qquad(\sigma\in\ell_\cap).
\]

This WDFA has the desired first-stage tradeoff. Scoring an extension is much cheaper than an LLM, comparable in latency to Markov model and is usually more faithful because the learned state can summarize a regular abstraction of the whole prefix rather than a fixed suffix. It also has a formal coverage guarantee: the $h$-RTN language is a support cover for all valid repairs in the Levenshtein ball. Increasing $h$ usually tightens the overapproximation but increases the automaton size, so we choose $h=3$. Finally, the WDFA is a language prior $P_{\hat\theta}(\sigma)$, not a conditional repair model $P(\sigma\mid\err\sigma)$; so we will need a conditional reranker to resolve.

\subsection{WDFA retrieval with LaTeR reranking}

The final stage restores the conditional information deliberately omitted from
the finite-state retriever.  For each repair instance, the WDFA decoder produces
a fixed candidate set
\[
  C_K(\err\sigma) = \operatorname{Top}_K^{P_{\hat\theta}}(\ell_\cap), \qquad K=512,
\]
or equivalently the top-$K$ candidates from $\widehat\ell_{h,\cap}$.  The Levenshtein-aligned Transformer Reranker (LaTeR) then
scores only this small list.

Let $\mathrm{LA}(\err\sigma,\sigma)$ be a Levenshtein alignment encoding whether each candidate token is matched, inserted, deleted, or substituted relative to the broken input.  LaTeR uses one encoder for the query and one alignment-aware
encoder for the candidate,
\[
  E_\phi(\err\sigma)\in\mathbb{R}^p, \qquad E_\phi'\big(\sigma,\mathrm{LA}(\err\sigma,\sigma)\big)\in\mathbb{R}^p,
\]
and assigns a scalar relevance score to each candidate $\sigma$,
\[
  r_\phi(\err\sigma,\sigma) = \mathrm{MLP}_\phi\Big( E_\phi(\err\sigma), E_\phi'\big(\sigma,\mathrm{LA}(\err\sigma,\sigma)\big) \Big).
\]
For a training pair $\langle\err\sigma,\sigma^\star\rangle$ and retrieved list
$C_K(\err\sigma)$, the listwise objective is
\[
  \mathcal{L}_{\mathrm{LaTeR}}(\phi) = -\sum_{\langle\err\sigma,\sigma^\star\rangle} \log \frac{\exp\big(r_\phi(\err\sigma,\sigma^\star)/\tau\big)} {\sum_{\sigma\in C_K(\err\sigma)\cup\{\sigma^\star\}} \exp\big(r_\phi(\err\sigma,\sigma)/\tau\big)}.
\]
At inference time, LaTeR reorders $C_{512}$ and returns the first few repairs to
the user:
\[
  \ell_\cap \xrightarrow{\text{WDFA retrieval}} C_{512}(\err\sigma) \xrightarrow{\text{LaTeR}} \operatorname{Top}_k C_{512}(\err\sigma).
\]
The separation is important.  The derivative/CFL machinery and the Nederhof
support cover determine which repairs can be retrieved; the WDFA determines how
quickly promising repairs enter the top-$512$; LaTeR only reorders the retrieved
list.  Thus reranking improves fidelity without weakening the validity or edit
locality guarantees, but it cannot recover a true repair that the retriever did
not place in $C_{512}$.

Further details on the LaTeR architecture and training procedure may be found in Appendix~\ref{sec:training}.
